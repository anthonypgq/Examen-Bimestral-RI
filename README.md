# Examen 1 Bimestre - Recuperación de Información

## Autor
Anthony Goyes

## Descripción
Sistema de recuperación de información utilizando embeddings y similitud coseno sobre el corpus Rotten Tomatoes Movies and Critic Reviews.

## Dataset utilizado
Rotten Tomatoes Movies and Critic Reviews Dataset.

## Funcionalidades
- Carga del corpus
- Preprocesamiento de texto
- Generación de embeddings
- Recuperación por similitud coseno
- Ejecución de 8 consultas obligatorias
- Tabla resumen de resultados
- Visualización PCA de embeddings
